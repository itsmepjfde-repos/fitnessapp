## Brand & Style

This design system is tailored for front-desk trainers, strength coaches, and facility directors operating in high-tempo, data-intensive athletic environments. The aesthetic marries high-performance athletic apparel design with surgical data tooling: dark obsidian foundations punctuated by electric energizing accents.

### Design Principles
- **Kinetic Precision:** Fast visual scanning under harsh gym lighting or varied tablet viewing angles. Dense information hierarchy without visual clutter.
- **Athletic Vitality:** High-contrast tactical surfaces driven by an intense kinetic lime and emerald spectrum, signaling momentum, stamina, and biometric readiness.
- **Physical Utility:** Large touch targets balanced against dense metric displays, allowing trainers to swiftly execute batch attendance checks, live assessment captures, and biometric chart reviews on tablets and desktop terminals.
- **Style Archetype:** Modern Technical Dark Mode with subtle tactical glass overlays, precision borders, and high-legibility tabular telemetry.

## Colors

The palette leverages a deep slate-obsidian substrate with high-energy kinetic accents. The primary and secondary emeralds anchor system state and progress indicators, while the tertiary volt-lime accent highlights critical interactive anomalies, PR breaks, and dynamic timers.

### Core Roles
- **Base Substrates:** Dark Obsidian (`#090D16`) serves as the canvas backdrop, with tiered elevated surfaces at Slate Void (`#0F172A`) and Tactical Slate (`#1E293B`).
- **Kinetic Emerald (Primary - `#10B981`):** Action confirmations, verified attendance, primary metric indicators, and system triggers.
- **Pulse Green (Secondary - `#22C55E`):** Positive delta tracking, heart rate recovery thresholds, and benchmark achievements.
- **Volt Strike (Tertiary - `#CCFF00`):** Live timers, high-priority biometric flags, active recording states, and physical assessment alerts.
- **Signal Tones:**
  - Alert / Cardiac Strain: Crimson Volt (`#EF4444`)
  - Warning / Capacity Load: Amber Flare (`#F59E0B`)
  - Rest / Neutral Recovery: Cool Cyan (`#06B6D4`)

## Typography

The typographic hierarchy is built on three distinct roles:
1. **Space Grotesk (Headlines):** Technical, angular geometry engineered for dynamic coaching dashboard headers, cohort identifiers, and high-impact zone statuses.
2. **Hanken Grotesk (Body & Interface Copy):** A refined, modern grotesque optimized for rapid reading of biometric notes, athlete health profiles, and table data.
3. **JetBrains Mono (Metrics & Telemetry):** Monospaced precision for tabular alignments, heart rates, 1RM values, timestamp recordings, and assessment delta values, eliminating layout shifting during live telemetry streams.

## Layout & Spacing

The portal is optimized for dual-operating modes: deskbound widescreen control terminals (1440px+) and handheld tablet units (768px - 1024px).

### Grid Strategy
- **Desktop (1025px+):** 12-column fluid grid system with `gutter-desktop` (24px) and `margin-desktop` (32px). Split workspaces (e.g., physical assessment scanner side-by-side with telemetry logs) occupy an asymmetrical 5:7 column distribution.
- **Tablet (768px - 1024px):** 8-column layout with `gutter` (20px) and `margin-tablet` (24px). Multi-column splits collapse into stacked segmented tab views or 4:4 equal distributions.
- **Mobile Handheld (Viewport < 768px):** 4-column fallback layout with `margin` (16px) focused strictly on batch attendance scanning and member quick-lookups.

### Spacing Rhythm
Component interiors rely on strict multiples of 4px. Compact controls use `space-xs` and `space-sm`, data card interiors use `space-md`, and chart dashboard cards standardise on `space-lg`.

## Elevation & Depth

Visual hierarchy does not rely on heavy, blurred drop shadows. In this high-intensity gym interface, depth is defined through low-contrast tactical outlines, luminous borders, and stacked surface opacity.

### Surface Tiers
- **Tier 0 (Backdrop):** `#090D16` solid canvas.
- **Tier 1 (Surface / Table Grid):** `#0F172A` with a 1px ghost border (`rgba(255, 255, 255, 0.07)`).
- **Tier 2 (Elevated Modules / Cards):** `#1E293B` at 90% opacity with `backdrop-filter: blur(12px)`. Outlines are crisp 1px borders using `rgba(255, 255, 255, 0.12)`.
- **Tier 3 (Modals / Overlays / Flyout Drawers):** `#131C2E` with an electric perimeter aura: `0 0 0 1px rgba(16, 185, 129, 0.2), 0 20px 40px -15px rgba(0, 0, 0, 0.8)`.

### Tactical Highlighting
Interactive elements gain immediate state focus not through drop shadow displacement, but via kinetic perimeter illumination (`box-shadow: 0 0 12px rgba(16, 185, 129, 0.35)`).

## Shapes

The interface embraces a low-radius, architectural, precision-milled visual form (`roundedness: 1`):
- Base interactive controls and inputs: `0.25rem` (4px).
- Metric badges, cards, data tables, and modal panels: `0.5rem` (8px).
- Specialized badge pills and status telemetry chips: constrained to `0.75rem` (12px) or full capsule when housing single monospaced data indicators.

## Components

### 1. Primary & Secondary Buttons
- **Primary Kinetic:** Background `#10B981`, foreground `#090D16`, typography `label-md` uppercase with `0.25rem` corners. Hover transitions to `#22C55E` with instant 100ms response.
- **Tertiary Quick-Action / Volt:** Background `#CCFF00`, foreground `#090D16`, used strictly for live session triggers (e.g., "START SESSION", "SYNC SCANNER").
- **Secondary Ghost:** Background `rgba(30, 41, 59, 0.6)`, 1px border `rgba(255, 255, 255, 0.15)`, text `#F8FAFC`.

### 2. Telemetry Badges & Status Chips
- Height: 24px (compact) or 32px (touch).
- Built with `label-sm` monospaced font.
- State-mapped fills with semi-transparent backdrops:
  - *Optimal / Checked In:* Background `rgba(16, 185, 129, 0.15)`, border `rgba(16, 185, 129, 0.4)`, text `#34D399`.
  - *At Risk / Load Spike:* Background `rgba(239, 68, 68, 0.15)`, border `rgba(239, 68, 68, 0.4)`, text `#F87171`.
  - *Standby / Pending Scan:* Background `rgba(204, 255, 0, 0.1)`, border `rgba(204, 255, 0, 0.35)`, text `#CCFF00`.

### 3. Clean Data Tables (Roster & Longitudinal Metrics)
- Header rows fixed in `label-sm`, uppercase tracking, text muted (`#64748B`), seated on `#090D16`.
- Row height: 48px standard, 56px in tablet touch mode.
- Alternating subtle row hover: `rgba(255, 255, 255, 0.03)` with an illuminated 2px vertical indicator on `#10B981` at the leading edge.
- Numeric columns strictly right-aligned with `metric-display` or `label-md`.

### 4. Batch Attendance Cards
- Container built on Tier 2 surface with large 48px touch targets for instantaneous toggling.
- State transitions: Instant color swap from muted slate (`#1E293B`) to vibrant kinetic edge (`rgba(16, 185, 129, 0.3)`) and checkmark display upon single tap or barcode scan event.

### 5. Physical Assessment Scanner/Uploader Split-Screen
- **Left Panel (Scanner/Feed):** Dark-room view with high-contrast tactical alignment reticles (`#CCFF00`), overlay guide lines for posture/movement plane tracking, and live FPS/resolution chips in `label-sm`.
- **Right Panel (Telemetry Parsing):** Structured input fields displaying real-time AI keypoint extractions, ROM (range of motion) degrees, and asymmetry percentages.

### 6. Longitudinal Progress Tracking Charts
- Minimalist background grids using `rgba(255, 255, 255, 0.05)`.
- Trendlines rendered in 2px kinetic emerald `#10B981` with neon gradient fills down to `rgba(16, 185, 129, 0.0)`.
- Target and threshold ceiling markers rendered in dotted `#CCFF00`.
